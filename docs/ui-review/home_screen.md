# Home screen

Reviewed 2026-10-02. Scope: `HomeScreen`, launcher, training snapshot, plan list/grid, plan menus, color picker, and split/preset entry points. Current code is the evidence; the old screenshots were not used.

## Findings

- **H01 · Medium · Verified by widget probe — day targets are too narrow.** Seven equally expanded columns share a row with six 8dp gaps (`lib/widgets/home/training_snapshot.dart:110`, `lib/widgets/home/training_snapshot.dart:114`, `lib/widgets/home/training_snapshot.dart:126`). Inside Home's 16dp gutters (`lib/screens/home_screen.dart:248`), each day target measures **44.3 × 76dp at 390dp**. Only days with workouts are actionable. Use a horizontally scrollable row with minimum 48dp slots, or open a separate day list.
- **H02 · Medium · Code-confirmed — plan actions are hidden in the default list.** `HomePlanRow` opens the workout on tap and shows actions only on long press (`lib/widgets/home/home_plan_row.dart:60`). Manage mode adds an explicit overflow button (`lib/widgets/home/plan_card.dart:120`), but the ordinary list does not. Expose the same labeled 48dp overflow control in both modes.
- **H03 · Medium · Unverified layout risk — plan dialogs cannot scroll.** The action menu is a plain `Dialog > ConstrainedBox > Padding > Column` (`lib/screens/home_screen.dart:399`, `lib/screens/home_screen.dart:413`); a middle plan can show six action rows. The color picker similarly uses a non-scrollable column and an ordinary action `Row` (`lib/screens/home_screen.dart:607`, `lib/screens/home_screen.dart:674`). Short landscape windows, long titles, or 2x text may clip actions. Add constrained scrolling and an `OverflowBar`; reproduce on a short viewport before choosing the final layout.
- **H04 · Medium · Code-confirmed — mutation feedback precedes persistence.** Duplicate calls async `addPlan` and immediately says “Plan copied” (`lib/screens/home_screen.dart:509`, `lib/screens/home_screen.dart:513`). Delete does not await or catch `deletePlan` (`lib/screens/home_screen.dart:571`); color Save closes before `updatePlan` completes (`lib/screens/home_screen.dart:688`, `lib/screens/home_screen.dart:691`). Those provider methods await storage (`lib/providers/workout_plan_provider.dart:27`, `lib/providers/workout_plan_provider.dart:34`, `lib/providers/workout_plan_provider.dart:64`). Await results, prevent repeat submissions, retain the dialog/draft on failure, and show an actionable error.
- **H05 · Low · Code-confirmed — picker spacing bypasses tokens.** Literal 16/12/8dp padding and gaps remain at `lib/screens/home_screen.dart:608`, `lib/screens/home_screen.dart:617`, `lib/screens/home_screen.dart:624`, `lib/screens/home_screen.dart:681`. Use `AppSpacing.lg/md/sm`; decide whether the 10/20dp gaps at `lib/screens/home_screen.dart:626` and `lib/screens/home_screen.dart:673` need an intentional component token.
