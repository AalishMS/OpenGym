# Shared controls and navigation

Reviewed 2026-10-02. Scope: shared set table/keypad, standard buttons, shell bottom navigation/rail, tutorial overlay, and shared modals. These are components rather than additional page screens. Old screenshots were not used.

## Findings

- **K01 · Medium · Verified by widget probe — keypad weight/rep values are absent from semantics.** `_contextField` provides a label, button and selected state, then `excludeSemantics: true`, without `value` (`lib/widgets/workout/set_entry_table.dart:937`). Labels supplied for weight/reps omit their numeric contents (`lib/widgets/workout/set_entry_table.dart:869`, `lib/widgets/workout/set_entry_table.dart:879`). A displayed 100 produced label “Set 1 Kg” and an empty semantic value. Add `value`, meaningful units, and an appropriate announcement when digits change. Affects Workout, Plan editor, and Edit workout, plus shared set sheets. The ordinary table field already supplies `value` (`lib/widgets/workout/set_entry_table.dart:625`); do not remove it.
- **K02 · Medium · Code-confirmed — fitting suppresses requested text enlargement.** Table values and keypad values use `FittedBox(scaleDown)` in fixed/proportional columns (`lib/widgets/workout/set_entry_table.dart:655`, `lib/widgets/workout/set_entry_table.dart:962`), and keypad context fields are fixed at 48dp height (`lib/widgets/workout/set_entry_table.dart:950`). Saved details use the same approach (`lib/widgets/history/workout_details_widgets.dart:391`). Larger text/long values are shrunk to fit; no-overflow tests alone miss this. Reflow or scroll columns using minimum readable widths, allow height to grow, and test actual rendered size at 1.3x/2x. Exact production-font shrink thresholds are unverified.
- **K03 · Medium · Code-confirmed — custom keypad has no physical numeric-key entry.** All edits route through tap-only `_type`/adjustment buttons (`lib/widgets/workout/set_entry_table.dart:737`, `lib/widgets/workout/set_entry_table.dart:1017`, `lib/widgets/workout/set_entry_table.dart:1079`). There is no editable text field, numeric-key handler, Shortcuts, or KeyboardListener in this component. Desktop users can focus/click buttons but cannot type a value directly, use Backspace, or submit with Enter as a number field. Add scoped hardware-key handling with focus and Escape/Enter behavior while retaining the touch keypad.
- **N01 · Low · Code-confirmed — same destination has different labels by viewport.** Compact navigation calls the main destination Home (`lib/widgets/app_bottom_nav.dart:27`); desktop rail calls it Plans (`lib/widgets/app_nav_rail.dart:29`). Choose one familiar name across both layouts, including tutorial copy.

## Checks that are already supported

- Standard labeled buttons have 48dp minima and token radii (`lib/theme/app_theme.dart:537`, `lib/theme/app_theme.dart:551`, `lib/theme/app_theme.dart:563`). A small visible icon/marker is not itself a target-size defect.
- Underline tabs have a minimum 48dp strip and full-height InkWell (`lib/widgets/underline_tab_strip.dart:151`, `lib/widgets/underline_tab_strip.dart:188`, `lib/widgets/underline_tab_strip.dart:253`). Its literal black shader stops are commented alpha masks under `BlendMode.dstIn` (`lib/widgets/underline_tab_strip.dart:165`, `lib/widgets/underline_tab_strip.dart:176`), a deliberate allowed exception, not UI foreground colors.
- Shell uses breakpoint-based rail/bottom navigation and preserves tab state (`lib/app_shell.dart:346`, `lib/app_shell.dart:355`, `lib/app_shell.dart:357`, `lib/app_shell.dart:381`). The rail has fixed 180dp width (`lib/widgets/app_nav_rail.dart:42`); short-height/2x-label behavior needs device verification, not an asserted overflow finding.
- Keypad unfocuses the prior field and opens a safe, scrollable sheet with a 680dp cap (`lib/widgets/workout/set_entry_table.dart:115`, `lib/widgets/workout/set_entry_table.dart:119`, `lib/widgets/workout/set_entry_table.dart:120`, `lib/widgets/workout/set_entry_table.dart:786`, `lib/widgets/workout/set_entry_table.dart:792`). Integral reps/RPE, decimal weights, bounds and decimal precision are enforced (`lib/widgets/workout/set_entry_table.dart:738`, `lib/widgets/workout/set_entry_table.dart:749`, `lib/widgets/workout/set_entry_table.dart:754`). Clear immediately changes the draft (`lib/widgets/workout/set_entry_table.dart:715`); Save closes it (`lib/widgets/workout/set_entry_table.dart:1119`). Whether a Done label would better describe this live editing is a product question, not a confirmed defect.
- Tutorial bubble has route/live-region semantics, scrollable prose, overflow-safe actions and reduced-motion handling (`lib/widgets/guided_tour.dart:315`, `lib/widgets/guided_tour.dart:424`, `lib/widgets/guided_tour.dart:451`, `lib/widgets/guided_tour.dart:400`). No new confirmed tutorial issue was found.
- Update dialog constrains/scrolls its content and tracks failure/progress states (`lib/widgets/update_dialog.dart:112`, `lib/widgets/update_dialog.dart:121`, `lib/widgets/update_dialog.dart:125`, `lib/widgets/update_dialog.dart:132`, `lib/widgets/update_dialog.dart:154`). Device installer behavior was not exercised.
- Picker accounts for keyboard insets and has minimum row targets (`lib/widgets/exercise_picker_sheet.dart:237`, `lib/widgets/exercise_picker_sheet.dart:800`). Preset browser has a scrollable content region and a responsive installation bar (`lib/widgets/splits/preset_browser_dialog.dart:137`, `lib/widgets/splits/preset_browser_dialog.dart:903`).

## Verification boundaries

Four temporary widget probes were run and then removed. They measured Home day width at 390dp, set-table width at a 238dp content constraint, keypad semantic data, and completed-workout drag scrolling. They used Flutter's default test typography; measurements do not certify actual Manrope/JetBrains rendering.

Real TalkBack/VoiceOver navigation, production-font screenshots, hardware keyboard behavior, Android keyboard/gesture insets, and short landscape windows remain unverified. Color solver/source tests passed, but that does not certify every custom composited header or rendered text pixel.
